# Sources & Media Directory — Danya Builds

This folder is the dedicated repository for all media used across **Danya Builds**.

## Supported Media

- **Videos (`.mp4`)**:
  - `cybersecurity1.mp4`, `cybersecurity2.mp4` — Security audits, terminal captures, threat detection walkthroughs
  - `ai1.mp4`, `ai2.mp4` — Model inference demos, agent workflows, neural network visualizations
  - `quantum1.mp4`, `quantum2.mp4` — Quantum circuit simulations, algorithm runs, visualization animations
- **Images (`.png`, `.jpg`, `.jpeg`, `.svg`, `.webp`)**:
  - Architecture blueprints and network diagrams
  - Certifications & credentials (Security+, AWS, CompTIA, etc.)
  - Benchmark performance graphs and research figures

All media placed in this folder can be referenced with clean relative paths, e.g. `<video src="sources/cybersecurity1.mp4">` or `<img src="sources/network-diagram.png">`.
