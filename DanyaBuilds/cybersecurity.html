Cryptographic Engineering

Symmetric Ciphers & Message Authentication

In modern secure communication, encryption without integrity verification exposes systems to chosen-ciphertext attacks. This project implements and evaluates the behavioral characteristics and security trade-offs of four fundamental AES operational modes:

  • ECB (Electronic Codebook): Deterministic substitution without an IV. Preserves visual and semantic patterns across identical 16-byte blocks, demonstrating why ECB is fundamentally vulnerable for structured data.
  • CBC (Cipher Block Chaining): Chains consecutive blocks with an Initialization Vector (IV), preventing pattern replication but requiring strictly sequential encryption and PKCS#7 padding.
  • CTR (Counter Mode): Converts the block cipher into a stream cipher using an incremental counter + nonce, enabling full parallelization of encryption and arbitrary stream lengths.
  • GCM (Galois/Counter Mode): Combines CTR mode confidentiality with universal hash-based authentication (GHASH), generating a cryptographic authentication tag alongside the ciphertext for tamper-proof data verification.
